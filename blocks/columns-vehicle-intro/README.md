# columns-vehicle-intro

Custom **columns** block. Purpose: model name heading beside the model-year links, on one keyline.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, two cells: model name heading | model-year links (list or paragraphs of links); an image-only cell renders as a media column.
