# table-pricing

Custom **table** block. Purpose: data table of body styles, powertrains, specs and prices.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: first row = column headers, then one row per variant; up to 4 columns in Universal Editor.

## Supported variations

| Variation | Option class |
| --- | --- |
| No Header | `no-header` |

## Universal Editor fields

- Content fields derived from the block's decorate contract.
- `classes` select for options: No Header.
