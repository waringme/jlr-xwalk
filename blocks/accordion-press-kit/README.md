# accordion-press-kit

Custom **accordion** block. Purpose: expandable model headers (model name and model year) revealing the press kits for that model.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per model: model name | model year (optional) | press kits (rich text, usually a cards-press-kit list or links).

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
