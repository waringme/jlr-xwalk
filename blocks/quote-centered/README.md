# quote-centered

Custom **quote** block: a centred pull quote between large quotation-mark glyphs, with a grey centred two-line attribution.

## Authoring (Universal Editor / xwalk)

Model: `standalone`

| Row | Content |
| --- | --- |
| 1 | Quotation (richtext, one paragraph) |
| 2 | Attribution (richtext): paragraph 1 = name, paragraph 2 = role |

The attribution row is optional; leave it empty for an unattributed quote.

## Supported variations

No variations.

## Universal Editor fields

- `quotation` (richtext): the quote text
- `attribution` (richtext): name and role, one paragraph each

## Reuse guidance

Use for a spokesperson pull quote in article copy. Design values come from
`stardust/prototypes/css/defender-en-gb-news-2026-07-tough-luxury-new-defender-vertex-leads-design-and-accessory-update.css` (`.article-quote`).
