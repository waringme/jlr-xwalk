# cards-press-kit

Custom **cards** block. Purpose: press kit list item: thumbnail, kit title, Download control and favourite star.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per press kit: image | title (heading or paragraph) + one or more download links (several links render as a format menu).

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.
